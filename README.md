# 🌐 Sharma Digital

A modern and professional digital agency website for **Sharma Digital**, showcasing services like Graphic Design, Digital Marketing, Music Distribution, and Video Editing.

---

## 🚀 About Project

Sharma Digital is a creative digital agency based in Nepal that helps businesses grow online through:

- Website Development
- Graphic Design
- Digital Marketing
- Music Distribution
- Video Editing

This website is built using **HTML and CSS** with a clean, modern, and responsive design.
